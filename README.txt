Owl-IN website — local preview

1. Откройте index.html двойным кликом.
2. Для публикации на GitHub Pages содержимое этой папки можно положить в репозиторий Owl-IN-ex.github.io.
3. Все изображения лежат локально в assets/, внешние библиотеки и CDN не используются.
4. При загрузке страницы сайт получает последний стабильный выпуск через GitHub Releases API и обновляет номер версии, ссылки на EXE, страницу релиза, размер файла и SHA-256.
5. Данные GitHub кешируются в браузере на 30 минут. Если API недоступен, остаются рабочие резервные данные версии 1.0.3.
